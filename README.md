# Battery Electric Vehicle Powertrain Modelling — MATLAB/Simulink

Academic electric-vehicle powertrain modelling project created in MATLAB/Simulink.

## Project overview

The work studies a battery electric vehicle (BEV) drivetrain, including electric motor and power-electronics components, using MATLAB/Simulink. The original submission considers vehicle performance and energy consumption over a drive cycle.

## Models

- `models/BEV_Components_OctNov24.slx` — components model.
- `models/BEV_Milg_OctNov24.slx` — BEV/drive-cycle simulation model.

**Upload status:** The model binaries are part of the original project archive but are not yet present in this repository. They should be uploaded without modification.

## Topics

Battery electric vehicles, Simulink, MATLAB, powertrain simulation, PMSM, inverters, vehicle dynamics, energy consumption, drive cycles, engineering modelling.

## Reproduce

1. Open MATLAB with Simulink and any required power electronics/Simscape toolboxes.
2. Open the original `.slx` models and resolve required external dependencies.
3. Review model parameters and select the documented drive cycle.
4. Run simulations and inspect plots and logged variables.

> This repository is documentation of an academic modelling exercise, not a validated design for vehicle control. Numerical results from the assignment must not be interpreted as independently reproduced.
