# Project presentation outline

1. **Motivation:** Understand energy demand and performance of a battery-electric powertrain.
2. **System architecture:** Battery, inverter, electric machine and drivetrain/vehicle load.
3. **Component modelling:** Explain how Simulink subsystems represent components and interfaces.
4. **Drive-cycle experiment:** Show inputs, speed response, and measured or logged variables.
5. **Results:** Report actual model output; distinguish computed vs assumed parameters.
6. **Limitations and next steps:** Dependency checks, parameter validation and sensitivity analysis.

## Suggested demo
Open the original `.slx` models, explain the top-level blocks and, if dependencies are available, run a selected drive cycle. Never describe unexecuted simulations as validated results.
